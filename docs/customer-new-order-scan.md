# 新增订单扫描

「客户管理 → 待归档」新增管理员按钮「扫描新增订单」。扫描仅生成待归档候选，不建立客户、不修改订单归属。

## 行为

- 选择未关联、未忽略且没有候选成员记录的租赁 1 / 租赁 2 订单。已有 pending / accepted / ignored / stale 成员均跳过；需要重新核对变更订单时使用全量扫描。
- 不以订单日期或上次完成任务的随机 ID 游标作为增量边界，覆盖补录历史日期和编号较小的新订单。
- 先分页读取必要的订单字段和候选成员 ID，形成最多 500 条的固定清单；随后只对清单内订单读取详情、计算匹配并写入候选。
- 清单和进度保存在原有扫描任务集合。中断继续同一清单；任务类型不可改变。清单内订单被删除、关联或被其他扫描抢先处理时安全跳过。
- 超过 500 条时提示再次扫描下一批。每次新的任务重新核对缺失候选，不依赖旧任务终点。
- 任务列表显示新增/全量类型、创建时间和进度。新按钮优先继续列表中的未完成新增任务。

## 接口及发布

新增 `manageCustomers` 动作 `scanNewOrders`，保持原来的管理员权限。旧接口 `scanUnlinkedOrders` 继续执行全量扫描。单独使用新动作，避免旧云函数静默执行全量扫描。

发布时先更新客户云函数，再更新前端。实现已在本地及隔离内存数据库验证，未对生产订单执行扫描或归档。

测试覆盖随机 ID、日期补录、历史候选排除、分页及上限、并发、失败重试、删除及关联竞争、权限和前后端接口配合。
