# HC Admin 功能更新通知

**更新主题：租赁二快捷转换与出库型号联动**

**发布日期：2026 年 8 月 22 日**

**使用范围：订单管理、出库记录**

各位同事：

HC Admin 已完成订单与出库流程的两项更新。本次更新减少重复录入，并补充来源关联与历史快照，方便订单人员和仓库人员协同处理。

## 一、订单支持快捷转租赁二

在订单管理页面，符合条件的既有租赁一订单现在可以直接创建：

- 部分转租赁二
- 全部转租赁二

### 适用条件

快捷入口会在以下订单中显示：

- 订单属性为“租赁一”；
- 订单类型为“新增业务”；
- 订单中包含实体货品；
- 当前用户拥有新增订单权限；
- 不是售后生成的订单，也不是已经生成的转租赁二订单。

### 操作方法

1. 进入“订单管理”，找到需要转换的既有订单。
2. 在该订单的“更多操作”中选择“部分转租赁二”或“全部转租赁二”。
3. 系统自动创建一份租赁二订单草稿，并带入原订单的客户、渠道、网店订单号、实体货品和附件信息。
4. 在货品步骤核对本次转换的货品范围，并填写金额、收款账户、已交租期和已交租金。
5. 确认无误后保存新订单。

### 业务规则

- 新订单会记录来源订单和转换方式，详情中可追溯原订单。
- 原订单不会被覆盖或改成租赁二；系统会新增一张关联订单。
- 转换订单属于虚拟业务订单，不需要出库，也不会重复生成物流记录。
- “部分转租赁二”和“全部转租赁二”会分别保留明确标识，便于后续查询和统计。

## 二、出库型号和数量改为与订单联动

由订单生成的出库记录，其型号和数量现在以关联订单为数据来源，统一显示为：

> 品牌 / 货品名称 / 规格　数量

例如：`苹果 / 苹果 8P / 64G　数量 30`

这解决了既有型号与新增型号格式不一致，以及修改货品时需要在订单和出库记录中重复操作的问题。

### 待出库记录

- 型号和数量只读展示，不再直接在出库记录中修改。
- 修改关联订单的货品或数量后，系统会自动同步到待出库记录。
- 如页面尚未刷新或需要立即核对，可点击“从订单同步”。
- 点击“查看关联订单”可直接定位并打开对应订单进行修改。

### 已出库记录

- 已完成的订单关联出库记录保留完成出库时的型号和数量快照。
- 后续修改订单不会改变已完成记录，确保历史出库凭证真实可追溯。
- 已出库记录不会显示“从订单同步”按钮。

### 手工出库记录

- 没有关联订单的手工出库记录继续支持独立添加、修改和删除型号。
- 历史手工记录不会因为本次更新被自动改写。

## 三、对现有数据的影响

本次更新不会批量修改现有订单或历史出库数据：

| 数据类型 | 更新后的处理方式 |
| --- | --- |
| 关联订单的待出库记录 | 以订单为准，可自动或手动触发同步 |
| 关联订单的已出库记录 | 保留历史快照，不再跟随订单变化 |
| 无关联订单的手工出库记录 | 保持原有编辑方式 |
| 既有订单 | 不自动转换，只有人工选择快捷操作后才新增租赁二订单 |

因此，本次更新不需要迁移历史数据，也不会覆盖既有订单和已完成出库记录。

## 四、使用注意事项

- 需要修改待出库型号或数量时，请进入关联订单修改，不要在两个页面重复维护。
- 点击“从订单同步”后，型号和数量已经即时更新；保存按钮仅用于保存客户名称、日期、快递单号等其他可编辑内容。
- 如果订单货品填写不完整，出库记录可能无法显示完整的“品牌 / 货品 / 规格”，请先补全订单货品信息。
- 如“查看关联订单”无法打开，请记录出库单客户名称、快递单号及发生时间，提交给管理员排查关联关系。

## 五、问题反馈

如使用中发现数据未同步、关联订单无法打开或转换信息带入不正确，请反馈以下信息：

- 订单序号；
- 客户名称；
- 出库记录或快递单号（如有）；
- 操作时间；
- 问题截图。

以上信息可帮助管理员快速定位并处理问题。
